# Airbnb Clone - Requirements Notes

## Functionalities

### 1. Hotel Management System
1. Create hotels
2. Create room types
3. Manage hotels
4. Manage room types
5. Manage bookings

### 2. Hotel Search System
1. Search hotels by `[startDate, endDate]`, City, No. of rooms
2. Get hotel details
3. Get room details

### 3. Hotel Booking System
1. Create booking with (startDate, endDate, no. of rooms, roomType)
2. Update guest information: adding guests, attaching guests to a booking
3. Make payments:
   - Payment success -> update booking status to `CONFIRMED`
   - Payment failed -> update booking status to `FAILED`
4. List all bookings
5. Manage bookings
